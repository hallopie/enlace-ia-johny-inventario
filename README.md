# Inventario de Armazones · Ópticas Johny
Dashboard de automatización desarrollado por Somos Enlace IA.

## Qué hace
Permite a los empleados de cada sucursal registrar armazones nuevos con foto, marcar ventas y consultar el inventario disponible — todo desde el celular, sin saber nada de Airtable.

## Cómo usarlo

### Ingreso de armazón
1. Selecciona tu sucursal
2. Toma foto del armazón (Claude lee marca, modelo y código automáticamente)
3. Ingresa el precio y notas opcionales
4. Toca "REGISTRAR ARMAZÓN"

### Registrar una venta
1. Selecciona tu sucursal
2. Ingresa el código del armazón (visible en Airtable o en la etiqueta)
3. Ingresa el nombre del cliente
4. Toca "REGISTRAR VENTA"

### Consultar inventario
1. Selecciona tu sucursal
2. Busca por marca o modelo (opcional)
3. Toca "BUSCAR"
